# 🌐 PSS

**Программные средства создания Internet-приложений**

Курсовой / практический проект, реализующий полноценное веб-приложение — от вёрстки до серверной логики — в рамках дисциплины «Программные средства создания Internet-приложений» (ПСС).

</div>

---

## 📖 О проекте

Этот репозиторий — практическая реализация задач и требований курса ПСС: связка фронтенда и бэкенда в одном рабочем приложении. В отличие от [collection-of-problems](https://github.com/sollcoun/collection-of-problems), где решаются отдельные учебные задачи по сборнику, здесь всё собрано в единый проект — с разметкой, стилями, интерактивностью и обработкой данных на сервере.

```

```

> Точный состав папок зависит от структуры проекта (например: `index`, `css`, `js`, `php` / `includes`, `db`) — обновится по мере развития репозитория.

## 🚀 Запуск проекта

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/sollcoun/PSS.git
   ```
2. Разместите папку проекта на локальном сервере с поддержкой PHP (например, через [OpenServer](https://ospanel.io/) или [XAMPP](https://www.apachefriends.org/)).
3. При необходимости настройте подключение к базе данных.
4. Откройте проект в браузере через локальный хост (например, `http://localhost/PSS/`).

## 🎯 Чему посвящён проект

- Семантическая HTML-вёрстка и адаптивная стилизация на CSS
- Интерактивность интерфейса на JavaScript / jQuery
- Обработка форм и бизнес-логика на PHP
- Хранение и выборка данных из базы данных
